# Placa Lora 32 Wifi 915mhz Sx1276 Esp32 Oled 0.96 Heltec Nfe

Descrição do Produto
A Placa WiFi LoRa 32 é uma solução completa de desenvolvimento voltada para projetos de Internet das Coisas (IoT) e comunicação M2M (Machine to Machine). Desenvolvida pela Heltec Automation, esta placa combina o microcontrolador ESP32 com o módulo transceptor LoRa SX1276, um display OLED integrado e sistema de gerenciamento de bateria de lítio.

Principais Destaques
Conectividade Robusta: Comunicação sem fio de longo alcance via LoRa 915 MHz (sensibilidade de até -148 dBm e alcance de até 2,6 km em área aberta).
Processamento de Alto Desempenho: Equipado com o chip ESP32 Dual Core operando a até 240 MHz com suporte a WiFi e Bluetooth Low Energy (BLE).
Interface Integrada: Display OLED de 0,96 polegadas (128x64 pixels) para exibição de dados e status em tempo real.
Gerenciamento de Energia: Circuito integrado de carga e descarga para baterias de lítio de 3,7 V (até 1000 mAh).
Design Compacto: Dimensões reduzidas (51 x 25 x 8 mm) ideais para automação residencial, industrial, rural e controle de sensores/atuadores.
